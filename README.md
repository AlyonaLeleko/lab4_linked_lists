# Лабораторная работа №4 - Связные списки

Реализованы все 11 заданий из методички без деления на варианты.

1. Однонаправленный список с `bottom`: вставка в конец O(1), удаление O(N), поддержка указателя хвоста.
2. Максимальный элемент несортированного списка O(N).
3-4. Добавление в начало и конец двунаправленного списка O(1).
5. Обе вставки используют общую функцию `insertCell`.
6. Удаление из двунаправленного списка O(N) с поиском, O(1) после нахождения узла.
7. Поиск имён от верхнего и нижнего ограничителей. Снизу может быть быстрее для имён ближе к концу, но худший случай остаётся O(N).
8. Сортированная вставка имён между двумя ограничителями O(N).
9. Проверка сортировки O(N).
10. Многопотоковый список планет: три цепочки указателей для сортировки по расстоянию, массе и диаметру. Это многопотоковый список как структура данных, а не параллельные потоки CPU.
11. Поиск и разрыв цикла методом «черепаха и кролик»: O(N) времени и O(1) памяти.

Запуск: `cmake -S . -B build && cmake --build build && ./build/lab4`.
Тесты: `ctest --test-dir build --output-on-failure`.

Полный список команд находится в `КОМАНДЫ_ТЕРМИНАЛА.txt`.
